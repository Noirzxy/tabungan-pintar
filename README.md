# Tabungan Pintar (Web View + Android APK)

Versi Web View interaktif dari aplikasi Android **Tabungan Pintar** (`com.aistudio.tabunganpintar.krmxyp`).

## Fitur Utama
- **Beranda**: Ringkasan total saldo tabungan, progres target keseluruhan, setoran/penarikan cepat, dan aktivitas terbaru.
- **Target Tabungan**: Buat dan kelola target berdasarkan kategori (`Darurat`, `Liburan`, `Gadget`, `Pendidikan`, `Lainnya`) dengan tema warna kustom.
- **Analitik**: Grafik pertumbuhan bulanan dan rincian alokasi dana per kategori.
- **Pengingat & Kalkulator**: Jadwal pengingat menabung serta kalkulator target harian/mingguan/bulanan.
- **APK Android**: File `apk/tabungan-pintar-debug.apk` tersedia langsung di repositori ini.
